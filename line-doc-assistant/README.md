# ผู้ช่วยรับเอกสารผ่าน LINE (LINE Smart Document Assistant)

เจ้าหน้าที่ถ่ายรูป/ส่ง PDF **หนังสือรับ** เข้า LINE → ระบบอ่านข้อมูล (OCR ภาษาไทย ทำในเครื่อง ไม่มีค่า AI รายเดือน)
→ **เจ้าหน้าที่ตรวจและกดยืนยัน** → คอมสำนักงานรับไฟล์ไปเก็บ แล้วลงทะเบียน → แจ้งผลกลับใน LINE

> **ใช้ลงทะเบียนหนังสือรับเท่านั้น** — หนังสือส่งยังลงที่คอมสำนักงานตามเดิม (ทำเสร็จที่คอมอยู่แล้ว)
>
> **สถานะตอนนี้: Demo Mode** — LINE จำลอง + ทะเบียนจำลอง ยังไม่แตะเว็บทะเบียนเดิมเลย
> การเชื่อมเว็บเดิมจะทำหลังได้รับ URL + ภาพหน้าจอจริง และได้รับอนุญาต (ดู `docs/ข้อมูลที่ต้องขอ.md`)

## สิ่งที่ระบบทำ / ไม่ทำ
| ทำ | ไม่ทำ |
|---|---|
| รับ PDF / JPG / PNG เฉพาะคนที่อยู่ในรายชื่อที่อนุญาต | ไม่สร้างระบบทะเบียนใหม่แทนของเดิม ไม่ออกเลขทะเบียนเอง |
| ตรวจลายเซ็น LINE, ตรวจชนิดไฟล์จริง, จำกัดขนาด, กัน PDF ที่ฝังสคริปต์/ไฟล์แนบ | ไม่แก้เว็บเดิม ไม่เขียนฐานข้อมูลเดิมโดยตรง ไม่ลบข้อมูลเดิม |
| อ่าน เลขที่หนังสือ / ลงวันที่ (รองรับ พ.ศ. + เลขไทย) / ส่วนราชการ / เรียน / เรื่อง | ไม่เดาข้อมูล — อ่านไม่ชัดจะขึ้น **"กรุณาตรวจสอบ"** |
| ให้เจ้าหน้าที่ตรวจ แก้ ยืนยัน หรือยกเลิก ก่อนบันทึก | ไม่บันทึกก่อนได้รับการยืนยัน |
| บันทึกผลผิดพลาด แจ้งเจ้าหน้าที่ | ไม่ส่งซ้ำอัตโนมัติ (ต้องตรวจในทะเบียนก่อนแล้วกดส่งใหม่เอง) |
| เก็บประวัติทุกขั้น: ใครส่ง ใครตรวจ เวลาไหน | ไม่ส่งเอกสารให้ AI ภายนอก (Claude API ปิดไว้) |
| ลบสำเนาบนเซิร์ฟเวอร์ **หลัง** ตรวจ sha256 ว่าคอมสำนักงานเก็บไฟล์ได้ครบแล้วเท่านั้น | |

## 1. ติดตั้ง Python (Windows 10/11)
1. โหลด **Python 3.12** ขึ้นไปจาก https://www.python.org/downloads/windows/
2. ตอนติดตั้ง **ติ๊ก "Add python.exe to PATH"** แล้วกด Install Now

## 2. ติดตั้ง Tesseract OCR (อ่านภาษาไทย)
1. โหลดตัวติดตั้งจาก https://github.com/UB-Mannheim/tesseract/wiki (ไฟล์ `tesseract-ocr-w64-setup-*.exe`)
2. ตอนติดตั้ง หน้า **Choose Components → Additional language data** ให้ติ๊ก **Thai**
3. ใช้ที่ติดตั้งเดิม `C:\Program Files\Tesseract-OCR\` (ถ้าเปลี่ยน ให้แก้ `TESSERACT_CMD` ในไฟล์ `.env`)

> ไฟล์ PDF ที่มีตัวอักษรอยู่แล้ว (ส่งออกจากเวิร์ด/ระบบสารบรรณอิเล็กทรอนิกส์) อ่านได้แม่นโดยไม่ต้องใช้ OCR
> ไฟล์สแกน/รูปถ่าย ใช้ OCR — **ตัวเลขไทยในรูปมักอ่านผิด ระบบจึงติดป้าย "กรุณาตรวจสอบ" ทุกครั้ง**

## 3. ติดตั้งโปรแกรม
1. คัดลอกโฟลเดอร์ `line-doc-assistant` ไปไว้ เช่น `D:\line-doc-assistant`
2. ดับเบิลคลิก **`install.bat`** (สร้าง `.venv` + ติดตั้งแพ็กเกจ + สร้างไฟล์ `.env` จาก `.env.example`)

## 4. ทดลอง Demo Mode
1. ดับเบิลคลิก **`start-demo.bat`** → เบราว์เซอร์เปิด http://localhost:8800 (ห้ามปิดหน้าต่างดำ)
2. ครั้งแรกจะให้ **สร้างบัญชีผู้ดูแลระบบ** (ชื่อผู้ใช้ รหัสผ่าน ยศ-ชื่อ)
3. เมนู **ตั้งค่า LINE** → เพิ่ม User ID ทดลอง เช่น `U11111111111111111111111111111111`
4. เมนู **จำลองการส่ง LINE** → เลือกไฟล์ PDF/รูป → กดส่ง → รอสักครู่ จะเห็นข้อความที่ LINE จำลองตอบกลับ
5. เมนู **เอกสารรอตรวจสอบ** → เปิดรายการ → ตรวจช่องสีเหลือง ("กรุณาตรวจสอบ") แก้ให้ถูก → **✓ ยืนยัน**
6. ดับเบิลคลิก **`start-agent.bat`** (ตัวรับงานคอมสำนักงาน) → ไฟล์ถูกคัดลอกไปที่ `OFFICE_INBOX`
   และบันทึกลง **ทะเบียนจำลอง** (`ทะเบียนจำลอง.json` ในโฟลเดอร์ `OFFICE_INBOX`) → LINE จำลองแจ้ง "บันทึกข้อมูลลงทะเบียนเรียบร้อยแล้ว"
7. ทดลองกรณีผิดพลาด: ใส่คำว่า `[จำลองผิดพลาด]` ต่อท้ายช่อง "เรื่อง" ก่อนยืนยัน → ระบบแจ้ง
   "ไม่สามารถบันทึกได้ กรุณาตรวจสอบที่คอมพิวเตอร์สำนักงาน" และ **ไม่ส่งซ้ำเอง**

## 5. เมนู Dashboard
| เมนู | ใช้ทำอะไร |
|---|---|
| ภาพรวม | จำนวนรอตรวจ / กำลังบันทึก / สำเร็จ / ผิดพลาด วันนี้ |
| เอกสารรอตรวจสอบ | ดูไฟล์ต้นฉบับคู่กับข้อมูลที่อ่านได้ → ยืนยัน / แก้ไข / ยกเลิก |
| ประวัติการรับเอกสาร | ค้นย้อนหลัง พร้อมไทม์ไลน์ว่าใครทำอะไรเมื่อไร |
| สถานะการเชื่อมต่อคอมสำนักงาน | คอมสำนักงานออนไลน์ไหม, รหัสเชื่อมต่อ (AGENT_TOKEN), งานค้าง |
| ตั้งค่า LINE | รายชื่อคนที่อนุญาตให้ส่ง, สถานะ Webhook |
| ตั้งค่าระบบ | บัญชีผู้ตรวจ, สำรองข้อมูล (ตรวจความสมบูรณ์ฐานข้อมูล + sha256 ทุกไฟล์) |

## 6. ไฟล์ข้อมูลอยู่ไหน / อัปเดตโปรแกรมไม่ให้ข้อมูลหาย
- ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ **`data\`** (ฐานข้อมูล `assistant.db`, ไฟล์ที่รับ, รหัสลับที่ระบบสร้าง `secrets.env`)
- อัปเดต: กด **สำรองข้อมูล** ในเมนูตั้งค่าระบบก่อน → ปิดโปรแกรม → คัดลอกไฟล์โปรแกรมใหม่ทับ **ยกเว้นโฟลเดอร์ `data` และไฟล์ `.env`**
- ไฟล์ `.env` และ `data\secrets.env` มีรหัสลับ ห้ามส่งให้ผู้อื่น

## 7. (ขั้นถัดไป) เปิดใช้ LINE จริง — ทำหลังได้รับอนุญาต
1. https://developers.line.biz/console/ → สร้าง Provider → สร้าง **Messaging API channel** (ได้ LINE OA ฟรี)
2. แท็บ Basic settings → คัดลอก **Channel secret**; แท็บ Messaging API → Issue **Channel access token (long-lived)**
3. ใส่ใน `.env`: `MODE=live`, `LINE_CHANNEL_SECRET=...`, `LINE_CHANNEL_ACCESS_TOKEN=...`, `PUBLIC_BASE_URL=https://ชื่อโดเมนอุโมงค์`
4. เปิดอุโมงค์ HTTPS ไปที่ `http://localhost:8800` (เลือกอย่างใดอย่างหนึ่ง)
   - **Cloudflare Tunnel** (ฟรี ต้องมีโดเมน): ติดตั้ง `cloudflared` → `cloudflared tunnel --url http://localhost:8800` (แบบทดลอง) หรือสร้าง named tunnel ผูกโดเมน
   - **ngrok** (ฟรี 1 โดเมนคงที่): `ngrok http --url=ชื่อ.ngrok-free.app 8800`
5. LINE Console → Messaging API → Webhook URL = `https://โดเมน/line/webhook` → Verify → เปิด **Use webhook**, ปิด Auto-reply
6. ให้เจ้าหน้าที่แอดเพื่อน LINE OA แล้วส่งไฟล์ — ระบบจะตอบ User ID ให้ ผู้ดูแลนำไปเพิ่มในเมนูตั้งค่า LINE

ข้อควรรู้
- เอกสารจะผ่านเซิร์ฟเวอร์ LINE (ต่างประเทศ) — **ห้ามส่งเอกสารชั้นความลับ**
- LINE OA แผนฟรีมีโควตาข้อความ push ต่อเดือน (ข้อความ "ได้รับเอกสารแล้ว" ใช้ reply ไม่เสียโควตา ที่เหลือเป็น push)
- ถ้าติดตั้งแบบ B (เซิร์ฟเวอร์อยู่นอกสำนักงาน) ให้ตั้ง `SERVER_URL` และ `AGENT_TOKEN` ใน `.env` ของคอมสำนักงาน

## 8. สำหรับนักพัฒนา
```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q                 # ทดสอบทั้งหมด
.venv/bin/python -m uvicorn app.main:create_app --factory --port 8800
.venv/bin/python agent/office_agent.py --once # ตัวรับงาน 1 รอบ
.venv/bin/python scripts/simulate_line.py tests/fixtures/memo-text.pdf --user U1111...  # ยิง webhook จำลองผ่าน HTTP
```
- โครงสร้าง: `app/` เซิร์ฟเวอร์ (FastAPI), `agent/` ตัวรับงานคอมสำนักงาน, `agent/adapters/` ตัวเชื่อมทะเบียน
  (`demo_register.py` ใช้งานได้, `legacy_web.py` ยังเป็นโครง — จะเขียนจากภาพหน้าจอจริงเท่านั้น)
- เอกสารออกแบบ: `docs/สถาปัตยกรรม.md`, รายการข้อมูลที่ต้องขอ: `docs/ข้อมูลที่ต้องขอ.md`
