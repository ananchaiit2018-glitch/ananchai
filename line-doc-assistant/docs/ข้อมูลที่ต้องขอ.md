# ข้อมูลที่ต้องขอจากผู้ดูแล (ก่อนเปิดใช้งานจริง)

ตอนนี้ระบบทำงานแบบ **Demo Mode** ทั้งหมด ยังไม่ได้เชื่อม LINE จริงและยังไม่ได้แตะเว็บทะเบียนเดิมเลย
จะเริ่มขั้นถัดไปได้ต้องมีข้อมูลด้านล่างก่อน (ห้ามเดาชื่อช่อง/ปุ่มของเว็บเดิม)

## 1. เว็บไซต์ทะเบียนหนังสือเดิม (จำเป็นที่สุด)
| # | ที่ต้องการ | หมายเหตุ |
|---|---|---|
| 1.1 | URL ที่ใช้เปิดเว็บทะเบียน (เช่น `http://localhost:8765`) | เปิดจากคอมสำนักงานเครื่องไหน |
| 1.2 | ยืนยันว่าเป็นโปรแกรม `digital-book-register` เวอร์ชันไหน หรือเป็นเว็บระบบอื่น | ถ้าเป็นระบบอื่นต้องขอภาพเพิ่ม |
| 1.3 | ภาพหน้าจอ **หน้า Login** | |
| 1.4 | ภาพหน้าจอ **หน้าเลือกเจ้าหน้าที่เวร / ผู้ลงทะเบียน** (ถ้ามี) | |
| 1.5 | ภาพหน้าจอ **หน้าลงทะเบียนรับ** แบบว่าง และแบบกรอกครบ (ไม่ต้องใช้หน้าทะเบียนส่ง) | ใช้ระบุช่องทีละช่อง |
| 1.6 | ภาพหน้าจอ **ตอนแนบไฟล์** | |
| 1.7 | ภาพหน้าจอ **หลังบันทึกสำเร็จ** (ที่เห็นเลขทะเบียน) | ใช้ตรวจผลจากเว็บจริง |
| 1.8 | ภาพหน้าจอ **หน้าเตือนรายการซ้ำ** และ **หน้าแจ้งข้อผิดพลาด** | ระบบจะหยุดและแจ้งเจ้าหน้าที่ |
| 1.9 | ภาพหน้าจอ **หน้ารายการทะเบียน** | ใช้ยืนยันว่าบันทึกเข้าแล้วจริง |
| 1.10 | ชื่อผู้ใช้สำหรับให้ตัวช่วยใช้ (แนะนำสร้างบัญชีแยก) | **รหัสผ่านไม่ต้องส่งในแชต** ตั้งในเครื่องสำนักงานเองผ่านตัวแปร `LEGACY_PASSWORD` |

## 2. LINE Official Account
| # | ที่ต้องการ | หมายเหตุ |
|---|---|---|
| 2.1 | สร้าง LINE OA + เปิด Messaging API (ฟรี) | ขั้นตอนอยู่ใน README หัวข้อ 7 |
| 2.2 | Channel secret และ Channel access token | **ใส่เองในไฟล์ `.env` บนเครื่อง ห้ามส่งในแชต** |
| 2.3 | รายชื่อเจ้าหน้าที่ที่อนุญาตให้ส่งเอกสาร | User ID (ขึ้นต้น U) ระบบจะแสดงให้เองตอนคนที่ยังไม่อนุญาตส่งมา |
| 2.4 | รายชื่อผู้ตรวจสอบ (บัญชี Dashboard) พร้อมยศ-ชื่อที่ใช้ลงทะเบียน | กำหนดสิทธิ์ admin / reviewer |

## 3. การติดตั้ง
| # | ที่ต้องการ | หมายเหตุ |
|---|---|---|
| 3.1 | เลือกแบบ A (ทุกอย่างอยู่คอมสำนักงาน + อุโมงค์ HTTPS) หรือ B (เซิร์ฟเวอร์ภายนอก + ตัวรับงานในสำนักงาน) | แนะนำ **แบบ A** ดู `docs/สถาปัตยกรรม.md` |
| 3.2 | อุโมงค์ HTTPS ที่จะใช้ (Cloudflare Tunnel ต้องมีโดเมน / ngrok มีโดเมนฟรี 1 ชื่อ) | LINE บังคับ HTTPS |
| 3.3 | โฟลเดอร์เก็บไฟล์ในคอมสำนักงาน (ค่าเริ่ม `D:\ทะเบียนหนังสือ\รับจาก LINE`) | |
| 3.4 | คอมสำนักงานเปิดเครื่องช่วงเวลาไหน | งานจะรอคิวถ้าเครื่องปิด |

## 4. การอนุญาต (ต้องได้รับก่อนเริ่มขั้นเชื่อมเว็บเดิม)
- [ ] สำรองข้อมูลระบบทะเบียนเดิมแล้ว (ใช้ปุ่มสำรองในโปรแกรมเดิม + คัดลอกโฟลเดอร์ `data` ไปเก็บ)
- [ ] อนุญาตให้ทดสอบกับ **ข้อมูลทดสอบ** ก่อน (เช่น สำเนาโปรแกรมเดิมอีกชุดที่ไม่ใช่ข้อมูลจริง)
- [ ] ผู้มีอำนาจรับทราบว่าเอกสารผ่านเซิร์ฟเวอร์ LINE — **ห้ามส่งเอกสารชั้นความลับ** ผ่านช่องทางนี้
- [ ] ยังไม่เปิดใช้ Claude API (ถ้าจะเปิดต้องมีหนังสืออนุญาต เพราะเป็นการส่งเอกสารให้ AI ภายนอก)
