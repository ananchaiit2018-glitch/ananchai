# คู่มือการใช้งาน — ระบบทะเบียนหนังสือรับ–ส่ง

## 1. ติดตั้งบน Windows (ทำครั้งเดียว)
1. ติดตั้ง **Node.js เวอร์ชัน 22 ขึ้นไป (LTS)** จาก https://nodejs.org (กด Next ไปเรื่อยๆ)
2. คัดลอกโฟลเดอร์ `digital-book-register` ไปไว้ในเครื่อง เช่น `C:\Register`
3. ดับเบิลคลิก **`install.bat`** (ต้องต่ออินเทอร์เน็ตครั้งแรกครั้งเดียวเพื่อดาวน์โหลดส่วนประกอบ)
   จะได้ไอคอน **"ทะเบียนหนังสือ"** บน Desktop
4. หลังติดตั้ง ใช้งานประจำวัน **ไม่ต้องใช้อินเทอร์เน็ต** และไม่มีข้อมูลถูกส่งออกไปภายนอก

## 2. เปิดโปรแกรม
ดับเบิลคลิกไอคอน **ทะเบียนหนังสือ** (รูปสมุดทะเบียนสีน้ำเงิน) บน Desktop หรือใน Start Menu → โปรแกรมเปิดเป็น **หน้าต่างแอปของตัวเอง** (ใช้ Microsoft Edge โหมดแอป ไม่มีแถบที่อยู่ มีไอคอนของโปรแกรมบน Taskbar) **โดยไม่มีหน้าต่างสีดำ** · ถ้าอยากให้เปิดในเบราว์เซอร์ปกติ ใส่ `"appWindow": false` ในไฟล์ `config.json`
บันทึกเร็ว: กด **Ctrl+S** ในหน้ากรอกหนังสือหรือหน้าตั้งค่า
เลิกใช้งาน: กดปุ่ม **ปิดโปรแกรม** ที่เมนูซ้ายล่าง (หรือดับเบิลคลิก `stop.bat`) · ถ้าลืมปิด ปล่อยทิ้งไว้ได้ ไม่เสียหาย
ถ้าเคยติดตั้งไว้แล้ว ให้ดับเบิลคลิก `install.bat` อีกครั้งเพื่อสร้างไอคอนแบบใหม่บน Desktop และ Start Menu (ไม่ต้องใช้อินเทอร์เน็ต) · ถ้าเปิดไม่ขึ้น ใช้ `start.bat` (มีหน้าต่างสีดำแสดงข้อความผิดพลาด) หรือดูไฟล์ `data\server.log`
ลองเล่นก่อนใช้จริง: ดับเบิลคลิก `start-demo.bat` (ข้อมูลตัวอย่างแยกจากข้อมูลจริง)

## 2.1 หน้าแรก: เลือกผู้เข้าเวร
เมื่อเปิดโปรแกรมจะขึ้นหน้า "ผู้เข้าเวร วิทยุ ประจำ มว.ฉก.ตชด.๔๔๔๑" ให้กดเลือกชื่อตนเอง (เปลี่ยนได้ภายหลังที่ชื่อตนเองมุมซ้ายล่างของเมนู) · เพิ่มหนังสือรับ/ส่ง กดปุ่มใหญ่ที่หน้าหลัก หรือปุ่ม "＋ เพิ่ม" ในหน้าทะเบียน ระบบจะใส่ชื่อเป็นผู้รับหนังสือให้อัตโนมัติ และบันทึกในประวัติว่าใครเป็นผู้ทำรายการ
แก้ชื่อหน่วย/หัวข้อ/เพิ่ม-ลบรายชื่อได้ที่ ตั้งค่าระบบ → ผู้เข้าเวร

## 4. ลงทะเบียนหนังสือ
เลือก **เพิ่มหนังสือรับ** หรือ **เพิ่มหนังสือส่ง** → กรอก ที่ / ลงวันที่ (วัน เดือน ปี พ.ศ.) / จาก / ถึง / เรื่อง / การปฏิบัติ / หมายเหตุ / ชื่อผู้ส่ง-ผู้รับ
→ กด **บันทึก** ระบบแสดงเลขทะเบียนที่ออกให้ (เช่น 005/2569)
- ช่องที่ต้องกรอก: **ลงวันที่** (เลือกจากปฏิทิน) และ **เรื่อง**
- ช่อง **ที่**: เลือกตัวนำหน้า (เช่น นร ๕๑๑๙.๑ (ร้อย ฉก.ตชด.๔๔๔)๘๔/) แล้วพิมพ์เฉพาะเลขหลัง / — เพิ่ม/แก้ตัวนำหน้าได้ที่ ตั้งค่าระบบ; ช่อง **จาก/ถึง**: เลือกจากรายการ หรือเลือก "อื่นๆ" เพื่อพิมพ์เอง (เพิ่มรายการที่ ตั้งค่าระบบ)
- **เลขทะเบียน ≠ เลขที่หนังสือ**: เลขทะเบียนระบบออกให้เอง แก้ไม่ได้ ส่วน "ที่" ท่านกรอกเอง
- **ผู้รับหนังสือ**: เลือกจากรายชื่อผู้เข้าเวร (ตั้งค่าได้ที่ ตั้งค่าระบบ → ผู้เข้าเวร) ระบบบันทึกและพิมพ์เป็น **ยศ+ชื่อ ไม่มีนามสกุล** ไม่มีการแนบลายเซ็นภาพ (ถ้าต้องการลายเซ็น ให้เซ็นปากกาบนกระดาษที่พิมพ์)
- แนบไฟล์ PDF/JPG/PNG ได้ครั้งละหลายไฟล์ (ไม่เกิน 20 MB ต่อไฟล์)
- กดบันทึกรัวๆ ไม่ทำให้เกิดรายการซ้ำ

## 4.1 ให้โปรแกรมอ่านรูปหนังสือแล้วกรอกให้ (OCR)
ด้านบนหน้าเพิ่มหนังสือมีกล่อง **"มีรูปหนังสือไหม? ให้โปรแกรมอ่านแล้วกรอกให้"**
1. กด **เลือกรูป** / ลากรูปมาวาง / หรือกด **Ctrl+V** วางรูปที่คัดลอกไว้ (JPG, PNG — สแกนหรือถ่ายจากมือถือ)
2. รอประมาณ 2–10 วินาที โปรแกรมจะกรอก **ที่ / ลงวันที่ / จาก / ถึง / เรื่อง** ให้ ช่องที่กรอกให้จะมี **กรอบสีเหลือง** และแนบรูปไว้ในไฟล์แนบให้เลย
3. **ตรวจทุกช่องที่เป็นสีเหลืองก่อนกดบันทึก** (โดยเฉพาะตัวเลข วันที่) แล้วเลือกชื่อผู้รับ → บันทึก
- อ่านในเครื่องนี้ทั้งหมด **ไม่ส่งรูปออกอินเทอร์เน็ต**
- โปรแกรมจะเทียบกับตัวนำหน้า "ที่" และรายการ จาก/ถึง ที่ตั้งไว้ ถ้าใกล้เคียงจะเลือกให้ตรงรายการเอง
- ได้ผลดีที่สุดเมื่อ: สแกนหรือถ่ายตรงๆ ไม่เอียง แสงพอ เห็นหัวหนังสือชัด ไม่มีเงา/ตราประทับทับตัวหนังสือ — รูปมัว/เอียง ตัวเลขไทยอาจอ่านผิด (เช่น ๑๔ เป็น ๔)
- ถ้าอ่านไม่ได้ กรอกเองได้ตามปกติ

**ต่อเลขจากสมุดเล่มเดิม:** ตั้งค่าระบบ → การ์ด "เลขทะเบียน" → กล่อง "ต่อเลขจากสมุดทะเบียนเล่มเดิม" ใส่เลขตัวสุดท้ายในสมุด (รับ/ส่ง) แล้วกด "ต่อเลขจากสมุด" โปรแกรมจะเริ่มเลขถัดไปให้

**กันลงซ้ำ:** ถ้า "ที่" ตรงกับรายการเดิม หรือเรื่อง+ลงวันที่ตรงกัน โปรแกรมจะเตือนก่อนบันทึก เลือก "กลับไปตรวจ" หรือ "บันทึกต่อ" (ถ้าเป็นคนละฉบับ) ได้

## 5. ค้นหา แก้ไข ยกเลิก
- **ทะเบียนหนังสือรับ/ส่ง** และ **ค้นหาหนังสือ**: พิมพ์คำค้นแล้วผลขึ้นทันที ค้นได้จาก เลขทะเบียน เลขที่หนังสือ เรื่อง หน่วยงาน ชื่อผู้ส่ง/ผู้รับ (พิมพ์หลายคำ = ต้องตรงทุกคำ)
  กรองตามปี/เดือน/สถานะ และเรียงตามเลขทะเบียนหรือวันที่ได้
- คลิกแถวเพื่อดูรายละเอียด ลายเซ็น ไฟล์แนบ และ **ประวัติการแก้ไข** → ปุ่ม **แก้ไข**
- **ยกเลิกรายการ**: ต้องใส่เหตุผล รายการยังอยู่ในระบบ (ขีดฆ่า) เลขทะเบียนเดิมถูกเก็บไว้และ **ไม่ถูกนำกลับมาใช้ใหม่**

## 6. พิมพ์และส่งออก (เมนู "รายงานและส่งออก")
เลือกประเภททะเบียน + ขอบเขต (รายเดือน / รายปี / ทั้งหมด / ช่วงวันที่ / เฉพาะรายการที่ติ๊กเลือกจากหน้าทะเบียน) + สี/ขาวดำ
→ **ดูตัวอย่างก่อนพิมพ์** (บังคับทุกครั้ง) → **พิมพ์** (กระดาษ A4 แนวนอน เลือก "ขนาดจริง/100%" ในหน้าต่างพิมพ์)
รูปแบบกระดาษตามสมุดทะเบียน: เส้นตั้งทึบแบ่งคอลัมน์ เส้นบรรทัดประ และเติมบรรทัดว่างให้เต็มหน้า
ดาวน์โหลดได้ทั้ง **PDF** (ฝังฟอนต์ไทย) **Excel (.xlsx)** และ **CSV** เรียงตามเลขทะเบียน
ทะเบียนหนังสือส่งแบบราชการไม่มีคอลัมน์ "จาก" (ติ๊กเพิ่มได้) รายการที่ยกเลิกจะแสดงว่า "(ยกเลิก: เหตุผล)" เพื่อให้เลขต่อเนื่อง

## 7. สำรองและกู้คืนข้อมูล (สำคัญ)
- เมนู **สำรองข้อมูล** → "สำรองข้อมูลตอนนี้" ได้ไฟล์ `.zip` เดียว (ฐานข้อมูล+ไฟล์แนบ+ลายเซ็น+ฟอนต์+โลโก้) และระบบแจ้งว่าสำเร็จหรือไม่
- ตั้ง **โฟลเดอร์สำรอง** ไปไว้ไดรฟ์อื่น/แฟลชไดรฟ์/โฟลเดอร์ที่ซิงค์ไว้ (เช่น `D:\Backup\Register`) — *ถ้าเก็บไว้เครื่องเดียวกับข้อมูล เครื่องเสียก็หายทั้งคู่*
- **สำรองอัตโนมัติ** (เมนู สำรองข้อมูล → ตั้งค่าสำรองอัตโนมัติ): เลือกความถี่ (1 ชม. – 7 วัน) จำนวนชุดที่เก็บ สำรองให้ทุกครั้งที่กด "ปิดโปรแกรม" **สำรองเป็นไฟล์ Excel (.xlsx)** ทุกครั้งด้วย (ทะเบียนรับ+ส่ง คนละแผ่นงาน เปิดดูได้โดยไม่ต้องใช้โปรแกรมนี้) และ **สำรองซ้ำไปอีกที่** เช่น แฟลชไดรฟ์ (แนะนำมาก) ระบบทำงานตอนเปิดโปรแกรมอยู่เท่านั้น หรือดับเบิลคลิก `backup-now.bat` เมื่อไรก็ได้
- **ไฟล์ Excel อัปเดตอัตโนมัติ** (เปิดเป็นค่าตั้งต้น): ทุกครั้งที่บันทึก/แก้ไข/ยกเลิกรายการ ระบบจะอัปเดตไฟล์ `ทะเบียนหนังสือรับ-ส่ง (อัปเดตอัตโนมัติ).xlsx` ในโฟลเดอร์สำรอง (และโฟลเดอร์ที่สองถ้าตั้งไว้) ให้ทันที รายการใหม่ต่อท้ายเรื่อยๆ ทะเบียนรับ+ส่งคนละแผ่นงาน · ที่หน้า Dashboard มีปุ่ม **เปิดไฟล์ Excel / เปิดโฟลเดอร์ / ส่งออก Excel (รับ+ส่ง ทั้งหมด)** · *ถ้าเปิดไฟล์นี้ค้างไว้ใน Excel ระบบจะอัปเดตไม่ได้ชั่วคราว เมื่อปิดไฟล์แล้วจะอัปเดตให้เองภายใน 1 นาที* — ถ้าต้องการแก้ไข/จัดรูปแบบ ให้กด "ส่งออก Excel" แล้วแก้ในไฟล์ที่ดาวน์โหลด
- **กู้คืน**: เลือกไฟล์สำรอง → ยืนยัน 2 ขั้น (① สำรองข้อมูลปัจจุบันแล้วหรือยัง — มีปุ่มสำรองตอนนี้ ② พิมพ์คำว่า "กู้คืน") ระบบสำรองข้อมูลปัจจุบันไว้ให้ก่อนเสมอ ชื่อ `before-restore-...`
- ฐานข้อมูลใช้โหมดป้องกันไฟดับ (WAL + sync เต็ม) ข้อมูลที่กดบันทึกแล้วจะไม่หายเมื่อไฟดับ
- ข้อมูลจริงอยู่ที่โฟลเดอร์ `data\` (ไม่อยู่ในโฟลเดอร์สาธารณะ เปิดดูไฟล์แนบได้ผ่านโปรแกรมเท่านั้น)

## 7.0 โฟลเดอร์เก็บหนังสือ (Drive D)
ทุกครั้งที่บันทึก/แก้ไข/แนบไฟล์ โปรแกรมจัดไฟล์ให้เองที่ **D:\ทะเบียนหนังสือ** (ถ้าเครื่องไม่มีไดรฟ์ D จะเก็บใน `data\ทะเบียนหนังสือ`) เปลี่ยนตำแหน่งได้ที่ เมนู **สำรองข้อมูล → โฟลเดอร์เก็บหนังสือ** (ปุ่ม 📁 เลือก…)
```
D:\ทะเบียนหนังสือ
 ├─ ทะเบียนหนังสือรับ.xlsx      ← อัปเดตทุกครั้งที่บันทึก คอลัมน์สุดท้าย "ไฟล์หนังสือ" กดเปิดไฟล์ได้
 ├─ ทะเบียนหนังสือส่ง.xlsx
 ├─ หนังสือรับ
 │   └─ 171169                  ← วันที่ลงทะเบียน (วว ดด ปป พ.ศ.)
 │       ├─ 01.pdf              ← หนังสือลำดับที่ 1 ของวันนั้น
 │       ├─ 02-1.jpg            ← หนังสือลำดับที่ 2 มีหลายไฟล์
 │       └─ 02-2.jpg
 └─ หนังสือส่ง
     └─ 171169
         └─ 01.pdf
```
- ลำดับ 01, 02 … นับตามลำดับที่ลงทะเบียนในวันนั้น (หนังสือที่ยกเลิกยังนับ เลขจึงไม่เลื่อน) — ดูว่าไฟล์ไหนเป็นหนังสือเรื่องอะไรได้จากคอลัมน์ "ไฟล์หนังสือ" ใน Excel
- แนบไฟล์เพิ่มทีหลัง: 01.pdf จะเปลี่ยนเป็น 01-1.pdf, 01-2.jpg ให้เอง
- ไฟล์อื่นที่วางเองในโฟลเดอร์นี้ โปรแกรมไม่ยุ่ง · ไฟล์ต้นฉบับยังเก็บในโปรแกรม (ถ้าโฟลเดอร์นี้หาย กด "จัดเก็บตอนนี้" สร้างใหม่ได้ทั้งหมด)
- ถ้าเปิดไฟล์ Excel ค้างไว้ ระบบจะอัปเดตไฟล์นั้นไม่ได้ชั่วคราว ปิดแล้วจะอัปเดตให้เองภายใน 1 นาที

## 7.1 ประวัติการใช้งาน (log)
เมนู **ประวัติการใช้งาน** แสดงว่า **ใคร ทำอะไร เมื่อไร จากเครื่องไหน** ระบบบันทึกให้อัตโนมัติ แก้ไขหรือลบผ่านโปรแกรมไม่ได้
- การเข้าใช้งาน: เปิด/ปิดโปรแกรม, เข้าเวร/เปลี่ยนผู้เข้าเวร, เข้าสู่ระบบ (รวมใส่รหัสผ่านผิด), ออกจากระบบ
- การลงทะเบียน: เพิ่ม/แก้ไข (บอกว่าแก้ช่องไหน)/ยกเลิกหนังสือ พร้อมเลขทะเบียน, แนบ/ลบไฟล์ — กดที่แถวเพื่อเปิดดูรายการนั้น
- พิมพ์ทะเบียน / ส่งออกข้อมูล, แก้ไขตั้งค่า (บอกหัวข้อที่เปลี่ยน), สำรอง/กู้คืนข้อมูล, สำรองอัตโนมัติ
- กรองได้ตาม วันนี้ / 7 วัน / เดือนนี้ / ช่วงวันที่, ผู้ทำรายการ, ประเภทการกระทำ และค้นหาคำ · กดชื่อด้านบนตารางเพื่อดูเฉพาะคนนั้น · ปุ่ม **โหลดเป็น Excel**
- รายละเอียดก่อน/หลังแก้ไขของแต่ละรายการยังดูได้ที่ "ประวัติการแก้ไข" ในหน้ารายละเอียดหนังสือเหมือนเดิม

## 7.2 ขึ้นปีใหม่ / ย้ายเครื่อง / เริ่มต้นใหม่ (หน่วยงานใหม่)
- **ขึ้นปีใหม่ (1 ต.ค.)**: ไม่ต้องทำอะไร เลขทะเบียนเริ่ม 001 ของปีใหม่ให้เอง ข้อมูลปีเก่าอยู่ครบ — แนะนำสำรองข้อมูลและพิมพ์ทะเบียนทั้งฉบับเก็บเข้าแฟ้มตอนสิ้นปี
- **ย้ายเครื่อง (หน่วยเดิม)**: เครื่องเก่า สำรองข้อมูลตอนนี้ → เอาไฟล์ zip ไปเครื่องใหม่ → ติดตั้งโปรแกรม → สำรองข้อมูล → กู้คืนจากไฟล์
- **เริ่มต้นใหม่ (ย้ายหน่วย / ส่งต่อเครื่อง / ล้างข้อมูลทดลอง)**: ตั้งค่าระบบ → การ์ดสีแดง **เริ่มต้นใหม่ (ล้างข้อมูล)** → ยืนยัน 2 ขั้น (① สำรองข้อมูลแล้วหรือยัง ② พิมพ์คำว่า "เริ่มใหม่")
  - ลบ: ทะเบียนทุกรายการ ไฟล์แนบในโปรแกรม ประวัติ การตั้งค่า รหัสผ่าน
  - **ไม่ลบ**: ไฟล์ Excel และรูปเอกสารในโฟลเดอร์เก็บหนังสือ (D:\ทะเบียนหนังสือ) และไฟล์สำรอง zip — ระบบสำรองข้อมูลให้อีกชุดก่อนลบเสมอ (before-reset-....zip) กู้คืนกลับได้
  - หลังเริ่มใหม่ โปรแกรมจะไม่เขียนทับหรือลบไฟล์ในโฟลเดอร์เก็บหนังสือของชุดเดิม (มีไฟล์ _ชุดข้อมูล-ห้ามลบ.txt บอกไว้) ให้เลือกโฟลเดอร์ใหม่ที่หน้าสำรองข้อมูล แล้วตั้งค่าตามรายการที่ขึ้นในหน้าตั้งค่า
  - ทำได้เฉพาะที่เครื่องหลัก

## 8. ใช้งานหลายเครื่องพร้อมกัน (ไม่บังคับ)
เปิดโปรแกรมที่เครื่องกลางเครื่องเดียว แก้ `config.json` เปลี่ยน `"host": "127.0.0.1"` เป็น `"0.0.0.0"` (และ **ตั้งรหัสผ่าน** ในหน้าตั้งค่า)
เครื่องอื่นในวงLANเปิด `http://<ไอพีเครื่องกลาง>:3000` ระบบออกเลขที่เครื่องกลางที่เดียว จึงไม่มีเลขซ้ำ ต้องอนุญาต Windows Firewall ให้พอร์ต 3000 ด้วย
**อย่าเปิดสู่อินเทอร์เน็ต** (โปรแกรมออกแบบสำหรับเครือข่ายภายในหน่วยงานเท่านั้น)

## 9. แก้ปัญหาเบื้องต้น
| อาการ | วิธีแก้ |
|---|---|
| กดไอคอนแล้วเปิดไม่ขึ้น | โปรแกรมจะขึ้นกล่องข้อความบอกสาเหตุ · ถ้าเป็นเรื่องพอร์ตถูกใช้ ให้ดับเบิลคลิก `stop.bat` (หรือรีสตาร์ทเครื่อง) แล้วเปิดใหม่ · ถ้ายังไม่ได้ ดับเบิลคลิก `start.bat` เพื่อดูข้อความ และดูไฟล์ `data\server.log` |
| install.bat ว่าไม่พบ Node.js | ติดตั้ง Node.js 22+ แล้วเปิด install.bat ใหม่ |
| หน้าเว็บขึ้น "ติดต่อโปรแกรมไม่ได้" | โปรแกรมถูกปิดไปแล้ว → เปิดจากไอคอนบน Desktop ใหม่ |
| "พอร์ต 3000 ถูกใช้งานอยู่" | เปิดโปรแกรมซ้อน ให้ปิดหน้าต่างเก่า หรือเปลี่ยน `port` ใน config.json |
| พิมพ์/ส่งออก PDF แล้วขึ้น "ยังไม่ได้นำเข้าไฟล์ฟอนต์" | ตั้งค่าระบบ → ฟอนต์ → นำเข้าไฟล์ .ttf (ปกติโปรแกรมนำเข้า TH SarabunIT๙ ให้เอง) |
| นำเข้าฟอนต์ไม่ได้ | ต้องเป็น .ttf/.otf/.woff ที่มีอักษรไทย (ไม่รับ .ttc/.woff2) |
| ตัวอักษรในกระดาษพิมพ์เล็ก/ใหญ่ไป | ตั้งค่าระบบ → ขนาดตัวอักษรเมื่อพิมพ์ (เช่น 16) |
| ลืมรหัสผ่าน | ปิดโปรแกรม แล้วลบแถว `password_hash` ในตาราง settings ของ `data\register.db` (หรือกู้คืนจากไฟล์สำรองก่อนตั้งรหัส) |
| ย้ายไปเครื่องใหม่ | ติดตั้งเครื่องใหม่ แล้วใช้ "กู้คืนจากไฟล์" ด้วยไฟล์สำรองล่าสุด |

## 10. ข้อจำกัดที่ควรทราบ
- ไม่มีระบบผู้ใช้หลายบัญชี/สิทธิ์ มีรหัสผ่านร่วมเพียงชุดเดียว (ไม่บังคับ)
- ประวัติการแก้ไขระบุชื่อผู้เข้าเวรที่เลือกไว้ แต่ไม่มีการยืนยันตัวตน (ไม่ใช่การล็อกอินรายบุคคล)
- การพิมพ์ใช้ตัวแสดงตัวอย่างของ Chrome/Edge: ในหน้าต่างพิมพ์ให้เลือกขนาดกระดาษ A4 แนวนอน และสเกล 100%
