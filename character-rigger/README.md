# Character Rigger

**เปิดมาจะเป็น "โหมดง่าย" สำหรับคนไม่ถนัดอนิเมชั่น** — ไม่ต้องรู้เรื่องกระดูกหรือคีย์เฟรม:
① เปิดตัวละคร หรือกด "🧩 สร้างจากรูปของฉัน" (เลือก PNG ชิ้นส่วนหลายไฟล์ แอพเดาว่าชิ้นไหนคืออะไรแล้วประกอบโครง+ท่าเดิน/โบกมือให้เอง)
② คลิกรูปชุดเพื่อสวม/ถอด หรือ "＋เพิ่มรูป" (ปรับขนาดให้อัตโนมัติ)
③ ลากชิ้นบนตัวละคร หรือใช้แถบเลื่อนปรับตำแหน่ง/ขนาด/หมุน (ย้อนกลับได้ Ctrl+Z)
④ กดท่าสำเร็จรูป ปรับความพริ้วของผม/ผ้า
⑤ ส่งออกแพ็คเกจเกม หรือคัดลอกคำสั่งให้ Claude
ปุ่ม "🔧 โหมดผู้เชี่ยวชาญ" มุมซ้ายบนเปิดเครื่องมือเต็ม (กระดูก/ไทม์ไลน์) ด้านล่าง

เครื่องมือเว็บไฟล์เดียว (`index.html`) สำหรับประกอบตัวละคร 2D จากชิ้นส่วนภาพ ใส่กระดูก ทำอนิเมชั่น
ผ้า/ผมพริ้วไหวด้วยฟิสิกส์สปริง และสลับ/ถอดชุดได้ แล้วส่งออกเป็นแพ็คเกจนำไปใช้ในเกมเว็บเบราว์เซอร์

เปิดใช้งาน: ดับเบิลคลิก `index.html` (ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์)

## ขั้นตอน
1. **นำเข้าชิ้นส่วน** PNG โปร่งใส (หรือกด "โหลดตัวอย่าง") → `+สลอต` ผูกกับกระดูกที่เลือก
2. **โหมด ① ตั้งโครง**: ลากจุดวงกลม = ย้ายกระดูก, ลากปลายกระดูก = หมุน, ลากรูป = เลื่อนตำแหน่งรูป
3. **ฟิสิกส์**: เลือกกระดูก → เปิด "ฟิสิกส์สปริง" (ผ้าหลายท่อน = กระดูกต่อกันเป็นโซ่ ใส่เฟสเพิ่มทีละข้อ)
4. **สวม/ถอดชุด**: รายการสลอตมีกล่องเลือกชุดให้ทุกสลอต ("— ถอด —" = ถอดออก) และบันทึกเป็น "ชุดสำเร็จรูป" ได้
5. **โหมด ② อนิเมชั่น**: "+ ใหม่" → เลื่อนเวลา → ลาก/แก้ค่ากระดูก (ใส่คีย์ให้อัตโนมัติ) → ▶ เล่น
6. **ส่งออก**: "⬇ ส่งออกแพ็คเกจเกม (.zip)" ได้ `rigger-runtime.js`, `character.json`, `images/`,
   `character.data.js`, `game-demo.html` และ `README.md` (บอก API และรายชื่อกระดูก/สลอต/ชุด/อนิเมชั่นของตัวละครนั้นๆ)
7. กด "📋 คัดลอกคำสั่งให้ Claude" แล้ววางพร้อมแนบ zip เพื่อให้ Claude สร้างเกมต่อจากตัวละครนี้

ข้อมูลโปรเจกต์บันทึกอัตโนมัติใน localStorage และบันทึกเป็น `.rigger.json` เพื่อเปิดกลับมาแก้ภายหลังได้

## ตัวอย่างพร้อมใช้: `samples/boy.rigger.json`
เด็กชายชุดนักเรียนกีฬา ตัดจากแผ่นชิ้นส่วนที่เจนด้วย AI (`samples/boy-parts/*.png`) มีกระดูก สลอต ผมสปริง
และอนิเมชั่น idle / walk / wave — กด "เปิดไฟล์…" แล้วเลือกไฟล์นี้ได้เลย
(สร้างใหม่ด้วย `python3 samples/build_boy.py`)

ข้อจำกัด: ยังไม่มีชิ้น "ลำตัวเปลือย" ใต้เสื้อ/กางเกง ถ้าถอดเสื้อจะเห็นช่องว่าง
ถ้าจะทำระบบถอดชุดจริง ให้เจนชิ้นลำตัว/ขา "เปล่า" เพิ่มแล้วใส่เป็นสลอตด้านหลังเสื้อผ้า

ตัวละครโครงมาตรฐาน (hip/body/head/armNear/legNear) ที่ยังขาดท่า กดปุ่ม “➕ เพิ่มชุดท่าสำเร็จรูป” ในโหมดง่าย
เกมตัวอย่างในแพ็คเกจ: กดเลข 1-9 เล่นท่าแบบครั้งเดียว (R = ลุกขึ้นหลังตาย)
