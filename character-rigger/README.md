# Character Rigger

เครื่องมือเว็บไฟล์เดียว (`index.html`) สำหรับประกอบตัวละคร 2D จากชิ้นส่วนภาพ ใส่กระดูก ทำอนิเมชั่น
ผ้า/ผมพริ้วไหวด้วยฟิสิกส์สปริง และสลับ/ถอดชุดได้ แล้วส่งออกเป็นแพ็คเกจนำไปใช้ในเกมเว็บเบราว์เซอร์

เปิดใช้งาน: ดับเบิลคลิก `index.html` (ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์)

## ขั้นตอน
1. **นำเข้าชิ้นส่วน** PNG โปร่งใส (หรือกด "โหลดตัวอย่าง") → `+สลอต` ผูกกับกระดูกที่เลือก
2. **โหมด ① ตั้งโครง**: ลากจุดวงกลม = ย้ายกระดูก, ลากปลายกระดูก = หมุน, ลากรูป = เลื่อนตำแหน่งรูป
3. **ฟิสิกส์**: เลือกกระดูก → เปิด "ฟิสิกส์สปริง" (ผ้าหลายท่อน = กระดูกต่อกันเป็นโซ่ ใส่เฟสเพิ่มทีละข้อ)
4. **สวม/ถอดชุด**: รายการสลอตมีกล่องเลือกชุดให้ทุกสลอต ("— ถอด —" = ถอดออก) และบันทึกเป็น "ชุดสำเร็จรูป" ได้
5. **โหมด ② อนิเมชั่น**: "+ ใหม่" → เลื่อนเวลา → ลาก/แก้ค่ากระดูก (ใส่คีย์ให้อัตโนมัติ) → ▶ เล่น
6. **ส่งออก**: "⬇ ส่งออกแพ็คเกจเกม (.zip)" ได้ `rigger-runtime.js`, `character.json`, `images/`,
   `character.data.js`, `game-demo.html` และ `README.md` (บอก API และรายชื่อกระดูก/สลอต/ชุด/อนิเมชั่นของตัวละครนั้นๆ)
7. กด "📋 คัดลอกคำสั่งให้ Claude" แล้ววางพร้อมแนบ zip เพื่อให้ Claude สร้างเกมต่อจากตัวละครนี้

ข้อมูลโปรเจกต์บันทึกอัตโนมัติใน localStorage และบันทึกเป็น `.rigger.json` เพื่อเปิดกลับมาแก้ภายหลังได้
