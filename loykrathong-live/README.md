# 🪷 ลอยกระทงไลฟ์ (TikTok LIVE แบบเรียลไทม์)

ฉากงานลอยกระทงสำหรับไลฟ์ TikTok แนวตั้ง 1080×1920 ที่ผู้ชมควบคุมได้ผ่านแชท ของขวัญ และหัวใจ
ผู้ชมแต่ละคนจะเป็นตัวละครใส่ชุดไทย โดยใช้รูปโปรไฟล์เป็นหัว และเดินเข้ามาในงานเอง

| ผู้ชมทำอะไร | เกิดอะไรบนจอ |
|---|---|
| เข้าห้องไลฟ์ | ตัวละครเดินเข้างาน และมีแจ้งเตือน "เข้าร่วมแล้ว" |
| พิมพ์ `ลอย ขอให้...` | เดินไปท่าน้ำ ลอยกระทงใบตอง และขึ้นคำอธิษฐานบนกระทง (ลอยฟรีได้ทุก 15 วิ) |
| พิมพ์ `รำ` / `เต้น` | ขึ้นเวทีรำวงวนเป็นวง |
| พิมพ์ `ไหว้` / `สาธุ` | ไปไหว้พระที่ศาลา |
| พิมพ์ `ชิงช้า` | ขึ้นชิงช้าสวรรค์ (โชว์รูปในกระเช้า) |
| พิมพ์ `โคม` | ปล่อยโคมลอยขึ้นฟ้า |
| พิมพ์เลข `1`–`6` | เปลี่ยนสีชุดไทย |
| พิมพ์อย่างอื่น | ขึ้นเป็นข้อความเหนือหัวตัวละคร |
| ส่งของขวัญ | ได้กระทงพิเศษตามราคา: บัวชมพู (1) · ดอกไม้รุ้ง (5) · ทอง (30) · หงส์ (99) · เรือหงส์ทอง + พลุ + ป้ายใหญ่ (299) |
| กดหัวใจ | หัวใจลอยจากตัวละคร และหลอดเป้าหัวใจเพิ่มขึ้น เมื่อครบเป้าจะมีพลุและโคมลอยเต็มฟ้า แล้วเป้าจะเพิ่มขึ้นอัตโนมัติ |
| ติดตาม / แชร์ | ขึ้นแจ้งเตือนขอบคุณ และมีพลุเล็ก |
| ทุก 5 นาที | นับถอยหลัง 30 วิ แล้วทุกคนในงานลอยกระทงพร้อมกัน |

มีป้าย TOP ของขวัญ และ TOP หัวใจ (เก็บแยกเป็นรายวันในเครื่อง)

## วิธีติดตั้ง (ครั้งแรก)
1. ติดตั้ง [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป บนคอมที่ใช้ไลฟ์
2. เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน
   ```bash
   npm install
   ```

## วิธีใช้ตอนไลฟ์
1. เปิดไลฟ์ TikTok ก่อน
2. รันเซิร์ฟเวอร์ (ใส่ชื่อบัญชีที่ไลฟ์อยู่)
   ```bash
   npm start -- ชื่อบัญชีtiktok
   ```
   หรือรัน `npm start` เฉย ๆ แล้วไปใส่ชื่อบัญชีที่แผงควบคุม
3. เปิดแผงควบคุมที่ http://localhost:8080/control.html แล้วดูว่าสถานะเป็นสีเขียว "เชื่อมต่อไลฟ์แล้ว"
4. เอาฉาก http://localhost:8080/ ไปขึ้นจอไลฟ์ โดยเลือกวิธีใดวิธีหนึ่ง
   - **OBS**: Sources → Browser → ใส่ URL `http://localhost:8080/` ตั้งความกว้าง `1080` สูง `1920` (ตั้ง Canvas ของ OBS เป็น 1080×1920 ด้วย) แล้วไลฟ์ด้วย Stream Key ของ TikTok
   - **TikTok LIVE Studio**: เปิดฉากในเบราว์เซอร์ Chrome แบบเต็มจอ แล้วเพิ่มแหล่งภาพแบบ "จับภาพหน้าต่าง/Window Capture"

> หมายเหตุ: ทั้ง OBS และ LIVE Studio ต้องไลฟ์จากคอมพิวเตอร์ และ TikTok จะเปิดให้ใช้เฉพาะบัญชีที่มีสิทธิ์ไลฟ์จากคอม

## ทดสอบโดยไม่ต้องไลฟ์
```bash
npm run demo
```
จากนั้นเปิด http://localhost:8080/ จะมีผู้ชมจำลองเดินเข้างาน พิมพ์ ลอย ส่งของขวัญ และกดใจให้ดูเอง
ที่แผงควบคุมมีปุ่มทดสอบ เช่น ส่งคอมเมนต์ ของขวัญ กดใจ เริ่มรอบลอยพร้อมกัน พลุ และโคม
(ถ้าเปิดไฟล์ `public/index.html` ตรง ๆ โดยไม่รันเซิร์ฟเวอร์ ฉากจะเข้าโหมดเดโมเอง)

## ปรับแต่ง
แก้ได้ที่ `public/config.js` ไฟล์เดียว:
- ชื่องาน คำสั่งในแชท และสีชุด
- ราคาของขวัญแต่ละขั้น (`giftTiers`)
- เป้าหัวใจ (`heartGoal`, `heartGoalStep`)
- ความถี่ของรอบลอยพร้อมกัน (`roundEveryMinutes`)
- คูลดาวน์ จำนวนตัวละครสูงสุด และ `spawnOnJoin` (ไลฟ์คนเยอะมากแนะนำให้ปิด จะให้เฉพาะคนที่พิมพ์เดินเข้างาน)
- คำต้องห้าม (`blockedWords`) ถ้าคำอธิษฐานมีคำในรายการ จะแสดงเป็น 🙏 แทน

ตั้งค่าเซิร์ฟเวอร์ผ่าน environment variable ได้ด้วย: `PORT` (ค่าเริ่มต้น 8080), `TIKTOK_USERNAME`, `SIGN_API_KEY`

## ข้อควรรู้
- ระบบดึงอีเวนต์ไลฟ์ด้วยไลบรารีไม่เป็นทางการ [tiktok-live-connector](https://github.com/zerodytrash/TikTok-Live-Connector)
  ซึ่งใช้เซิร์ฟเวอร์เซ็นของ Euler Stream (โควตาฟรีมีจำกัด) ถ้าเชื่อมต่อบ่อยแล้วโดนจำกัด
  ให้สมัครคีย์ที่ eulerstream.com แล้วรันแบบ `SIGN_API_KEY=คีย์ npm start -- ชื่อบัญชี`
- TikTok อาจเปลี่ยนระบบเมื่อไรก็ได้ ถ้าวันหนึ่งเชื่อมต่อไม่ได้ ให้ลอง `npm update tiktok-live-connector`
- ห้องที่คนเยอะมาก TikTok อาจไม่ส่งอีเวนต์กดใจและเข้าห้องมาครบทุกครั้ง แต่ส่งคอมเมนต์และของขวัญครบ
- ไม่ควรสัญญาว่าจะให้ของรางวัลหรือเงินตอบแทนกับการส่งของขวัญ เพราะขัดกฎ TikTok
